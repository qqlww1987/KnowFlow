# Design Document

## 1. 预设基线声明
- **Profile 选择**: `profiles/strategic.md` (战略规划)
- **选择理由**: 本演示文稿为面向工程技术决策者的技术方案展示，涉及系统架构、实施路径与投资回报分析，与战略咨询报告的逻辑框架高度吻合。
- **参考维度**: 中高信息密度控制、数据驱动的说服力、稳健且具有高级感的视觉风格、严谨的内容表达规范。
- **偏离说明**: 
  - 色彩上摒弃常规的商务蓝，转而采用建筑行业相关的深石墨灰+琥珀金配色，以契合工程造价与基建主题。
  - 图像上摒弃常规的城市天际线，选用高质量的基建施工现场、桥梁结构及工程蓝图作为视觉素材。

## 2. 风格基准声明
- **风格锚点 1**: 麦肯锡/BCG 战略咨询报告 — 参考其严密的逻辑架构、信息密度控制、专业严谨的数据呈现方式以及高度克制的装饰风格。
- **风格锚点 2**: Monocle 杂志 — 参考其高品质的编辑排版、自信且极具对比度的字体层级、通过大量留白与极细线条构建的版面秩序感。
- **参考维度说明**: 
  - 咨询报告：逻辑推演、数据图表的视觉占比、章节层级与页面导航体系。
  - Monocle：字体排版哲学、色彩克制感、极具品味的图文混排比例。

## 3. 风格细节

### 配色设计
- **整体倾向**: 保守稳健，兼具现代感与工程领域的工业力量感。
- **色彩温度**: 偏冷的中性基调（石墨灰），辅以温暖的矿物点缀（琥珀金）。
- **背景色 (background)**: `#F5F4F0` (暖石灰) — 带有微弱纸张质感的暖灰色，彻底摒弃简陋的纯白，营造顶级印刷物的阅读体验。
- **主色 (primary)**: `#2C3539` (深石墨) — 极深的蓝灰色，作为标题、核心结构与视觉骨架，传递绝对的专业感与权威感。
- **正文色 (text)**: `#3D4145` (炭灰) — 用于正文阅读，对比度舒适，避免纯黑的生硬。
- **辅助色 (secondary)**: `#8B8C7A` (暖石灰) — 用于分割线、次要信息及图表坐标轴，构建细腻的层级。
- **强调色 (accent)**: `#C8963E` (琥珀金) — 仅在关键 KPI 数字、高亮节点及图表核心系列上克制使用，呼应重型机械的工程美感。
- **深色背景 (darkBg)**: `#1E2426` (深墨灰) — 用于封面、过渡页及图表强调底色。

### 字体设计
- **中文字体**: `MiSans` — 干净现代，字形饱满，提供极佳的屏显阅读体验。
- **英文字体**: `Liter` — 现代新怪诞风格，低对比度，比例均衡，针对屏幕优化，简洁理性，极具技术感。
- **字号层级**:
  - 封面标题: 44px, 加粗, 字间距加宽 (构建宏大叙事感)
  - 章节标题: 40px, 加粗
  - 页面标题: 28px, 加粗
  - 正文: 18px (确保大屏阅读的清晰度，绝不低于 18px)
  - 注释/数据源: 13px
  - 大数字 (KPI): 56px, 加粗, 使用琥珀金色

### 容器与装饰风格
- **内容组织**: 极度依赖网格对齐、留白对比与字号差异来构建信息层级。
- **卡片使用**: 仅在必须分组时使用卡片。卡片采用直角矩形，无边框，使用极浅的灰色填充（如 `#EEEDEA`），严禁使用圆角与阴影。
- **装饰元素**: 
  - 极细的直线（1px，辅助色）作为板块间的物理或逻辑分隔。
  - 强调色细线（2px，accent）作为标题旁的点缀或底部稳定线。
  - 克制使用图标，仅在列表或三维矩阵中作为视觉锚点。

### 图像与图表风格
- **配图风格**: 高质量、写实风格的基建工程摄影（桥梁结构、施工机械、工程蓝图）。要求光线硬朗、构图严谨，严禁使用卡通插画或低质素材图。
- **图表风格**: 极简专业风。优先使用琥珀金作为主数据列，辅助列使用石墨灰的不同透明度。去除所有冗余的网格线、背景填充与图例边框。
- **表格风格**: 严谨的三线表变体。深石墨色表头配白字，数据行采用无底色与暖灰底色交替，仅保留极细的水平分隔线。

## 4. 布局体系

### 全局布局特征
- **画布尺寸**: 16:9 标准比例。
- **页边距**: 保持宽阔的四周留白（如左右 60px，上下 50px），营造呼吸感。
- **全局元素**: 
  - 页面底部固定放置 1px 的强调色底线（贯穿全宽或位于特定网格内）。
  - 页面右下角固定放置页码（13px，辅助色）。
  - 摒弃复杂的顶部导航栏，保持版面纯粹。

### 特殊页面布局
- **封面 (Hero 设计)**: 全尺寸底图 + 深色渐变蒙版（从左至右加深）。左侧居中放置巨大的白色标题文字，底部左侧放置副标题，构建第一眼震撼。
- **目录页 (非对称双栏)**: 拒绝干瘪的项目符号。左侧放置巨型“CONTENTS”字样或带有渐变蒙版的局部工程图；右侧使用严格的网格排版章节序号与标题，序号使用琥珀金。
- **章节过渡页 (休止符)**: 采用与封面呼应的深色背景（`#1E2426`）。页面一侧放置半透明的巨大章节序号（如“01”），另一侧居中放置章节标题与简短的导语，重置视觉疲劳。

### 正文页布局模式
- **数据看板 (KPI 页)**: 顶部标题，下方横向均分 3-4 个 KPI 模块，每个模块包含巨大的琥珀金数字 + 深色指标名称 + 简短的趋势说明。
- **左右分栏**: 适用于图文页。一侧放置占据 50% 宽度的严谨工程图（可带有细线边框），另一侧使用更大的字号（20px）阐述要点。
- **网格矩阵 (架构/方案页)**: 适用于展示原始文件清单或知识库。将卡片等宽排列（如 3 列或 4 列），卡片顶部配以行业图标，内部使用多层级列表。
- **逻辑推演布局**: 适用于技术方案。使用横向贯穿的箭头、流程节点或阶梯状布局，清晰展示 AI 生成的实施路径。

## 5. 样式使用规则
- `$title`: 仅用于页面核心标题，必须保持单行，使用主色。
- `$subtitle`: 用于封面副标题或章节导语，使用辅助色。
- `$body`: 用于所有正文段落与列表，确保 1.6 倍行高。
- `$bigNumber`: 仅用于核心 KPI 数据，使用琥珀金，必须与底部的解释文本形成强烈的字号对比。
- `$label`: 用于图表数据源标注、 tiny 脚注及卡片内的分类标签。
- `$primary` 填充：用于表头、核心流程节点背景。
- `$accent` 填充：仅用于最高级别的强调，如大数字、图表中需要突出的单一系列。

## 6. 风险禁止项
- **严禁使用圆角**：所有形状、图片裁剪、卡片必须为直角，以契合基建工程的刚硬与权威感。
- **严禁正文字号过小**：正文字号绝对不可低于 18px，注释不可低于 12px。
- **严禁使用俗套的“科技蓝/紫”**：严格锁定在石墨灰+琥珀金的工业配色体系内。
- **严禁图文不对齐**：在左右分栏布局中，必须确保图片与文本块的顶部或中心完美对齐，底部不得出现参差不齐的“悬空”状态。
- **严禁干瘪的列表**：在目录页或要点页，禁止使用简单的项目符号堆叠，必须通过网格、线条或卡片将其结构化。
- **严禁滥用强调色**：单页中琥珀金的出现面积不得超过 10%，仅用于点睛之笔。

theme:
  colors:
    primary: "#2C3539"
    secondary: "#8B8C7A"
    accent: "#C8963E"
    background: "#F5F4F0"
    text: "#3D4145"
    darkBg: "#1E2426"
    cardBg: "#EEEDEA"
  textStyles:
    title:
      fontSize: 28
      color: "$primary"
      fontFamily: "Liter, MiSans"
      lineHeight: 1.3
    subtitle:
      fontSize: 18
      color: "$secondary"
      fontFamily: "Liter, MiSans"
      lineHeight: 1.5
    body:
      fontSize: 18
      color: "$text"
      fontFamily: "Liter, MiSans"
      lineHeight: 1.6
    bigNumber:
      fontSize: 56
      color: "$accent"
      fontFamily: "Liter, MiSans"
    label:
      fontSize: 13
      color: "$secondary"
      fontFamily: "Liter, MiSans"
      lineHeight: 1.4
  tableStyles:
    default:
      fontSize: 14
      fontFamily: "Liter, MiSans"
      headerFill: "$primary"
      headerColor: "#FFFFFF"
      headerBold: true
      bodyFill: ["#FFFFFF", "$cardBg"]
      bodyColor: "$text"
      border:
        style: solid
        width: 1
        color: "#D1CFCA"
